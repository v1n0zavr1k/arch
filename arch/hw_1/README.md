# SIMD Computing

Учебный проект: Scalar / SIMD вычисления на C++20.

## Зависимости (macOS)

```bash
xcode-select --install
brew update
brew install cmake ninja xsimd googletest libomp
```

## Сборка

```bash
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build
ctest --test-dir build --output-on-failure
./build/simd_demo
```

Если CMake не обнаружит OpenMP автоматически, можно явно передать пути Homebrew:

```bash
cmake -S . -B build -G Ninja \
  -DCMAKE_BUILD_TYPE=Release \
  -DOpenMP_ROOT="$(brew --prefix libomp)"
```

## Структура

- `include/simd/operations`: обобщённые Scalar-операции.
- `include/simd/matrix`: Scalar matrix multiplication.
- `include/simd/core`: общие политики выполнения.
- `tests`: тесты корректности.
- `src`: демонстрационное приложение.

Этап 1 создаёт проверяемую Scalar-основу и инфраструктуру сборки.
SIMD-ядра и параллельные реализации будут добавлены следующим этапом.


## Отчет по работе

### Цель

Подготовить проверяемую основу проекта для последующей реализации векторизованных операций SIMD: определить scalar-версии вычислительных ядер, общую политику выполнения и инфраструктуру сборки и тестирования.

### Реализованные компоненты

- **Поэлементная арифметика:** обобщенное ядро `binary_transform_scalar` применяет переданную операцию к элементам двух массивов. Определены сложение, вычитание, умножение и деление. Целочисленное деление на ноль приводит к `std::domain_error`.
- **Функции активации:** реализованы SiLU и tanh-аппроксимация GELU для типов с плавающей точкой.
- **Редукции:** реализованы сумма и среднее. Среднее накапливается в `double`; для пустого диапазона возбуждается `std::invalid_argument`.
- **Умножение матриц:** реализовано скалярное умножение матриц row-major размеров `rows × inner` и `inner × cols`; нулевые указатели проверяются.
- **Политика выполнения:** объявлен `ExecutionPolicy` со значениями `Scalar` и `SIMD` для выбора варианта вычислений на следующих этапах.
- **Демонстрация:** приложение показывает сложение массивов, сумму, среднее, SiLU и GELU.
- **Сборка:** CMake настраивает C++20, библиотеку xsimd, опциональную поддержку OpenMP, демонстрационную программу и тесты GoogleTest.

### Проверка

Набор тестов покрывает сложение чисел с плавающей точкой, ошибку деления целых на ноль, сумму и среднее, обработку пустого диапазона, значения SiLU и GELU в нуле, а также умножение двух матриц 2 × 2. Сборка и запуск тестов выполняются командами из раздела «Сборка» выше.

### Результат и дальнейшая работа

Получена модульная scalar-реализация, пригодная как эталон для проверки SIMD-версий. В текущем этапе SIMD-ядра и параллельные реализации еще не реализованы; это следующий этап проекта. Фактический результат запуска сборки и тестов в рамках подготовки этого отчета не проверялся.
